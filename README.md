# Placement Predictor 🎓

A machine learning project that predicts student placement chances based on academic and skill-related factors.

## 🎯 Objective

Help students understand their placement probability and identify areas for improvement.

## 🌐 Live Demo

https://placement-predictor-3-2zdt.onrender.com

## 🛠️ Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## ⚙️ Key Features

* Data preprocessing and cleaning
* Machine learning model training
* Model evaluation and prediction
* Interactive prediction interface
